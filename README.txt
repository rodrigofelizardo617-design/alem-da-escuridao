PUBLICAÇÃO GRATUITA — GITHUB PAGES
1. Crie uma conta em github.com, se ainda não tiver.
2. Crie um repositório público novo.
3. Envie todos os arquivos desta pasta, mantendo a pasta assets.
4. No repositório, abra Settings > Pages.
5. Em Source, selecione Deploy from a branch.
6. Escolha a branch main e a pasta /root.
7. Salve. O GitHub fornecerá o endereço gratuito do site.

IMPORTANTE:
O site usa apenas HTML, CSS e JavaScript, então não precisa de servidor ou banco de dados.
